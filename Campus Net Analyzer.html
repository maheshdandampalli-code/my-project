How it works

  • Model: devices are vertices, cables are undirected edges weighted by latency (ms). Stored as an adjacency list, rebuilt after every failure.
  • Connectivity: a BFS flood fill counts connected components. More than one segment means part of the campus is cut off.
  • Routing: Dijkstra finds the lowest-latency path in O(V²); BFS finds the fewest-hop path in O(V+E).
  • Resilience: Tarjan's algorithm finds articulation points, the devices whose failure splits the network, in O(V+E) using discovery time and low-link values.

Extension ideas: import real topology from SNMP/traceroute data, add bandwidth-aware routing, or compute edge betweenness to rank critical links.
